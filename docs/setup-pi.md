# Pi free-preview operator runbook

This profile stays in preview: it uses legacy production with research disabled and starts with `doctor`. It does not log in, send Telegram, or publish Facebook content by itself.

Create a non-secret config from the existing example and run `npm run sfurti -- command --json '{"type":"setup-posting-windows"}'` once. The command only writes a missing windows template; it never overwrites an existing file. Replace its provisional evidence with operator-supported Bangladesh audience evidence before readiness can pass.

Start the opt-in stack with `docker compose -f docker-compose.pi-free.yml up`. Stop it with `docker compose -f docker-compose.pi-free.yml stop`. Use `backup` with a new directory, then `restore-verify` into a separate empty directory; reauthenticate private runtime credentials separately and reconcile any restored remote history before any later authorized submission.

ARM64 capacity, Page access, private delivery, and public publication remain operator-only checks.
