# Add evidence-led original content without removing legacy clip production

Sfurti's new research mode accepts global multilingual sources, produces Bangla originals and uses a rolling content mix, while the existing licensed-clip workflow remains available. Independent AI topic/evidence validation and artifact review govern routine publication, with human editorial attention only for critical exceptions; source disagreement gets one reconciliation pass and must not be resolved by selecting the mission-favorable finding. This preserves useful production controls while requiring separate scientific provenance, media provenance and publication-eligibility checks.
