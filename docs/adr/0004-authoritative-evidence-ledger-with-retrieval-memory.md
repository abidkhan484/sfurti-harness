# Keep evidence decisions authoritative outside retrieval memory

Sfurti will use Cognee to retrieve related research while the harness ledger owns source and claim versions, approvals, dependencies, withdrawals and publication history. This permits rebuilding or replacing retrieval memory and immediately blocking stale claims despite delayed index updates, at the cost of explicit synchronization and provenance checks. The Research → Content Engine spec defines this approved design; implementation remains tracked separately.
