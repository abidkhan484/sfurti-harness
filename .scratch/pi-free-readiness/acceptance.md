# End-to-end acceptance scenarios

Status: ready-for-agent

Each scenario needs an automated deterministic regression unless marked on-device/operator. Tests use synthetic owned media and local HTTP fakes; never real accounts by default.

| ID  | Scenario                                                                          | Required result                                                                                                                                            |
| --- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A01 | Load Pi profile and existing legacy/process profile                               | Pi defaults preview, ChatGPT-only, 3/1/1 and 90-day target; old valid profiles continue loading                                                            |
| A02 | Config contains API-key auth or stray API-key environment                         | Pi rejects paid-auth configuration and never forwards ambient paid credentials                                                                             |
| A03 | Codex refresh then container recreation                                           | Refreshed auth survives, separate role sessions remain isolated, secrets absent from logs                                                                  |
| A04 | Quota exhaustion during generation, then restart                                  | Stage/session/model retained, no new render version, no paid fallback, retry is bounded                                                                    |
| A05 | Reviewer receives prompt injection from a transcript                              | Content treated as data; no tools, no producer context, invalid outputs rejected                                                                           |
| A06 | Metadata-only discovery hit                                                       | Recommendation is pending, no rights/qualified flag or invented reviewed interval                                                                          |
| A07 | Valid READY source submission scanned twice                                       | One imported identity, one permission registration, retained integrity and original untouched                                                              |
| A08 | Half-copy, path traversal, symlink, ID conflict, expired or restricted permission | Held with reason; no qualification/production or out-of-root file read                                                                                     |
| A09 | Source registration would exceed free-space/managed budget                        | No partial approved registration; originals remain; low-space report includes needed bytes                                                                 |
| A10 | Registered file is modified                                                       | Qualification and publication fail current integrity checks                                                                                                |
| A11 | Actual source qualified                                                           | Evidence binds source hash/topic/mission; intervals in bounds; candidate selector uses one valid unused set                                                |
| A12 | Only one qualified source supplied for daily volume                               | One custom sample can work; daily three-source deficit remains explicit                                                                                    |
| A13 | Same render request repeated after successful render or crash                     | Completed output reused; partial stages resumed/fenced, no unrelated deletion                                                                              |
| A14 | Bangla image/text with conjuncts, long caption and HTML/filter metacharacters     | Readable layout, safe escaping, no arbitrary script/command execution or external resource load                                                            |
| A15 | Reel contains corrupt frames, silence, bad subtitles or ASR gaps                  | Inspector fails/holds relevant criterion; producer assertions cannot pass review                                                                           |
| A16 | Foreign video lacks translate scope or approved voice                             | Held; original-Bangla path still works; no fallback provider                                                                                               |
| A17 | Run setup sample while doctor false and Telegram/Facebook configured              | Exactly one unscheduled custom artifact; zero external mutations and queued notifications                                                                  |
| A18 | Invoke publish/cancel/service-cycle/Telegram publish in preview                   | No Facebook mutation, no fictitious remote success; other eligible local work can continue                                                                 |
| A19 | Telegram success response saved then retry                                        | Same result; no second known-success send; media actually uploaded                                                                                         |
| A20 | Telegram response lost or partial attachment send                                 | Unknown components held, no automatic duplicate send; update polling survives restart without lost commands                                                |
| A21 | Facebook upload acknowledged but processing incomplete                            | Not published; resume polling same upload/remote IDs                                                                                                       |
| A22 | Facebook response lost without authoritative correlation                          | Uncertain state blocks resubmission; no absence inferred from incomplete search                                                                            |
| A23 | Single selected publish authorization with other posts queued                     | Only selected Page/artifact/hash submitted; service remains inactive                                                                                       |
| A24 | Windows cannot fit five posts or evidence is missing                              | Validation/doctor fail actionable gate; no fabricated schedule/evidence                                                                                    |
| A25 | Tick crosses/misses exact minute or render runs long                              | Due work catches up once by durable date/opportunity; leases maintained; source shortage does not starve text/images                                       |
| A26 | Planned 90 days but only some approved artifacts                                  | Coverage reports actual backed days and size estimate; target unchanged                                                                                    |
| A27 | Setup attestation forged, stale, changed file/Page/model or fixture-only receipts | Relevant readiness gates fail; doctor itself sends nothing                                                                                                 |
| A28 | Backup restored into isolated directory                                           | Checksums/references/schema verified, secrets excluded, original DB untouched                                                                              |
| A29 | ARM64 Pi full-day preview (operator)                                              | Three distinct-source clips + image + text approved within 24 h; record memory, disk, temperature/throttling observations, quotas and all quality failures |
| A30 | Selected Facebook smoke (operator, separately authorized)                         | Remote ID + read-back evidence; if uncertain, preserve uncertainty and do not activate recurring publication                                               |

Completion evidence must distinguish mocked HTTP, local x86/native, ARM64 on-device, account read and real public write. Any failed on-device quality/capacity check remains visible even if all unit tests pass.
